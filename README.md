# ccbp-pytorch (wip)

Implementation of CCBP (Continuous Continual Backpropagation), [Learning Continually at Peak Performance with Continuous Continual Backpropagation](https://openreview.net/forum?id=UJqXhFFzKu), and [Continual Backprop](https://arxiv.org/abs/2108.06325)

## Install

```bash
$ pip install ccbp-pytorch
```
